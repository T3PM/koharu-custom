# Project: Koharu Manga Suite Review Implementation (AGY-CR-20261026-MANGA-SUITE-001)

## Architecture
Koharu is a desktop manga translation and editing environment combining a Rust backend (Tauri v2 + bespoke crates) and a TypeScript/React frontend (`packages/koharu` via `@koharu/bridge`).
- `crates/koharu-scene`: Core ECS document model, schema-versioned persistence (`bincode` + `revisioned`), reversible `Patch` system, and entity edit operations.
- `crates/koharu-pipeline`: Computer vision and NLP stages (text detection, layout classification, inpainting morphology, LLM translation).
- `crates/koharu-translator`: External/local translation engine integrations and onomatopoeia lexicons.
- `crates/koharu-app`: Tauri application commands, RPC endpoints, project workspace lifecycle, and `tauri-specta` protocol generation.
- `packages/bridge`: Type-safe TypeScript bindings generated purely by `tauri-specta` from `koharu-app`.
- `packages/koharu`: React/Tailwind/WASM desktop UI with Canvas/WebGPU rendering, Inspector, and multi-lingual localization.

## Interface Contracts

### koharu-scene ↔ koharu-app (Persistence & Document Mutation)
- `GlossaryEntry`: Revision 2. Field `character: Option<CharacterProfile>` tagged with `#[revision(start = 2)]`. Backward decode for v1 maps missing `character` to `None`.
- `Patch::prune_missing`: Accumulates `next_state: SceneState` sequentially across ops. Returns diagnostics vector for rejected ops.
- `Edit::remove_entity`: Returns `Result<(), Error>`, failing with `Error::EntityNotFound` if entity is absent. Batch helpers use `remove_entity_if_present`.
- `Edit::set_speaker`: Signature `set_speaker(&mut self, entity: EntityId, speaker: Option<GlossaryEntryId>, origin: Origin) -> Result<(), Error>`.

### koharu-pipeline ↔ koharu-scene (Mask & Detection Contracts)
- `write_mask`: Filters regions by kind: only `RegionKind::Text` or `RegionKind::Bubble` are rendered into inpaint masks.
- `InpaintingProcessor`: Morphological dilation re-clipped to `input.region` bounding box. SFX dilation only targets layers possessing `TextRole("dev.koharu.text.sfx")`.
- `DetectionProcessor`: Preserves existing translated layers upon re-detection unless explicit destructive overwrite requested.

### koharu-app ↔ packages/bridge (Tauri IPC & Protocol Contract)
- `protocol.ts`: 100% generated via `cargo run -p koharu-app --bin generate`. Zero manual diffs.
- `set_balloon_shape`: Exported with discrete named union types for shapes, avoiding inline anonymous enums.
- `update_character_profile`: Named request struct `UpdateCharacterProfileRequest { entry_id: GlossaryEntryId, profile: CharacterProfile, expected_revision: u64 }`.
- `set_bubble_speaker`: Typed as `speaker: Option<GlossaryEntryId>` across Rust and TypeScript.

### packages/koharu ↔ Desktop CEF (Live Verification)
- CEF remote debugging endpoint exposed at `http://127.0.0.1:4000`.
- Inspector updates handle `RevisionConflict` by invalidating query cache, refetching latest revision, and retrying queued mutations.

## Code Layout
- `crates/koharu-scene/src/components/`: ECS components (`glossary.rs`, `character.rs`, `structure.rs`).
- `crates/koharu-scene/src/`: Core engine (`patch.rs`, `document.rs`, `edit.rs`, `tests.rs`).
- `crates/koharu-pipeline/src/stages/`: Execution stages (`detection.rs`, `inpainting.rs`, `translation.rs`, `execution.rs`).
- `crates/koharu-translator/src/`: Translation logic (`onomatopoeia.rs`).
- `crates/koharu-app/src/commands/`: Tauri commands (`glossary/rpc.rs`, `glossary/domain.rs`, `project.rs`, `editing.rs`).
- `crates/koharu-app/src/bin/`: Generator CLI (`generate.rs`).
- `packages/bridge/src/`: Specta output (`protocol.ts`).
- `packages/koharu/components/editor/`: UI components (`Inspector.tsx`, `GlossaryEntryRow.tsx`, `GlossarySettingsPopover.tsx`).
- `packages/koharu/locales/`: i18n JSON catalogs (`en/`, `ja/`, `ko/`, `zh-CN/`, etc.).
